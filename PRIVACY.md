# Privacy Policy for Toggle Tab

Last updated: 2026-04-10

Toggle Tab does not collect, transmit, sell, or share personal data.

## What the extension stores

Toggle Tab stores the following data locally in your browser by using `chrome.storage.local`:

- Your configured keyboard shortcut
- A short list of recently visited tab IDs used for tab switching

This data stays on your device and is not sent to any remote server.

## Permissions used

- `tabs`: used to detect the current tab, maintain recent-tab history, and activate the selected tab
- `storage`: used to save the shortcut configuration and recent-tab state locally
- `host_permissions` on `<all_urls>`: used so the content script can listen for the configured shortcut on webpages

## Data collection and sharing

Toggle Tab:

- does not use analytics
- does not use remote code
- does not send data to external servers
- does not sell user data
- does not use data for advertising
